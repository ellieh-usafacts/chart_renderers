chart_renderers

Custom output renderers for LangSmith runs.

  • langsmith_chart_renderer.html — the renderer itself. Blank on its own; it draws the chart card only once LangSmith posts a run output. Point LangSmith's custom renderer at this URL.
  • fixtures/harness.html — local test harness. Posts a sample payload into the renderer and exercises the dedup and re-render paths.

The renderer expects { type: "output", data: { chart_json, wrapper_json } } via postMessage: chart_json is the Flourish spec, wrapper_json the card's title and subtitle.

langsmith_chart_renderer.html is generated from chart.html, aeonik-medium.woff2 and renderer_shell.html by build_renderer.py — edit those, then re-run python3 build_renderer.py and commit the result.
